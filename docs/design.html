Watching your terminal AI from your phone — privately

remote-claw is a small tool you install next to a terminal coding-AI agent (like Claude Code or Codex). It lets you watch and steer that session from another device, over the internet, without the relay in the middle being able to read it. This page explains, in plain terms, how it protects you and what each piece is for.

plain-language design the relay is a dumb, blind mailbox one identity per machine
