Encrypted multiplayer for the coding agents you already use

remote-claw's target is to add multiple browser collaborators to Claude Code, Codex, OpenCode, and an honest lower-fidelity tmux fallback through a zero-knowledge, end-to-end encrypted broker while keeping the local TUI and provider-native collaboration where available. The shared core is a developer beta; the full surface matrix is not implemented yet, and model routing—including Anthropic, OpenAI, and Bedrock—remains a separate choice.
