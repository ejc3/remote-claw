# Connor's Room — The Board

The design board for Connor's room: measured floor plan, wall-by-wall elevations,
the Crate & Barrel walnut line, paint, budget, alternatives considered — plus the
narrated two-minute film.

**Static site, zero build.** `index.html` is the landing page, `/board` is the full
design board, `/film/connor-room-walkthrough.mp4` is the film.

## Deploy on Vercel

1. vercel.com → Add New → Project → import `ejc3/connor-room-board`
2. Framework preset: **Other** (no build command, output dir = repo root)
3. Deploy — done. Suggested domain: `connor-room-board.vercel.app`

Part of a three-site suite: board · 3D room · palette.
