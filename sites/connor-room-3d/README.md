# Connor's Room — The 3D Room

An interactive three.js walkthrough of Connor's room at true dimensions.
Self-contained single file (`room.html`) — the three.js bundle is inlined, no
network requests, no build step. `index.html` is the landing page.

## Deploy on Vercel

1. vercel.com → Add New → Project → import `ejc3/connor-room-3d`
2. Framework preset: **Other** (no build command, output dir = repo root)
3. Deploy. Suggested domain: `connor-room-3d.vercel.app`

Part of a three-site suite: board · 3D room · palette.
