# Connor's Room — The Atelier Palette

The companion paint board: six Witch Hat Atelier-inspired paints mapped onto the
room's elevations, plus the reflected ceiling plan, sigil how-to, and paint schedule.
Static site, zero build. `index.html` is the landing page, `/palette` is the board.

## Deploy on Vercel

1. vercel.com → Add New → Project → import `ejc3/connor-room-palette`
2. Framework preset: **Other** (no build command, output dir = repo root)
3. Deploy. Suggested domain: `connor-room-palette.vercel.app`

Part of a three-site suite: board · 3D room · palette.
